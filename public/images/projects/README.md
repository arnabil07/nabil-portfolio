# Project screenshots

`project-01.webp`, `project-02.webp` and `project-03.webp` are **dummy illustrations** (not real projects).
Replace them with screenshots of projects you built (WebP/PNG/JPG, ~1600x1000) and reference them in `data/projects.ts`,
e.g. `screenshot: "/images/projects/my-app.webp"`. Only use screenshots of your own work.
